FOOTBALL CAREER 27 — FINAL DESIGN PACKAGE

المحتويات:
- index.html: اللعبة والواجهة العربية.
- manifest.json + sw.js: إعدادات التثبيت والعمل دون اتصال بعد أول تحميل.
- icon-192.png و icon-512.png: أيقونة التطبيق.

مهم بخصوص APK:
هذه الحزمة نسخة ويب قابلة للتثبيت كتطبيق PWA على أندرويد، وليست ملف APK ثنائياً.
لم يتم إنشاء APK هنا لعدم توفر Android SDK/Gradle في بيئة البناء.
للتثبيت الآن: ارفع محتويات المجلد إلى استضافة HTTPS، افتح الرابط في Chrome على الهاتف، ثم من القائمة اختر Install app أو Add to Home screen.
لإنتاج APK لاحقاً: يمكن تغليف المشروع باستخدام Bubblewrap/TWA أو Capacitor بعد إعداد بيئة Android SDK.

اللعبة الحالية نموذج محاكاة إداري 2D. أسماء اللاعبين وبياناتهم وقيمهم تجريبية/تقريبية وليست قاعدة بيانات رسمية مرخصة من EA.
